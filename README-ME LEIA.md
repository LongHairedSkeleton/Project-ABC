# ABC Simples - Plataforma Educacional Gamificada

> Projeto Open Source de apoio à alfabetização e diagnóstico de aprendizagem para alunos do 1º ao 3º ano do Ensino Fundamental.

---

## Sobre o Projeto

O ABC Simples é uma ferramenta pedagógica desenvolvida por alunos do 9º ano com o objetivo de tornar o aprendizado mais interativo e dinâmico nos anos iniciais da vida escolar.

A plataforma utiliza gamificação (desafios, pontuação e recompensas) para reforçar conteúdos de leitura, escrita e lógica matemática alinhados à Base Nacional Comum Curricular (BNCC), além de auxiliar professores no diagnóstico de defasagens apontadas por avaliações como as do CAEd.

### Principais Destaques

- **Acessibilidade para Alunos:** Interface intuitiva e visual para crianças em fase de alfabetização.
- **Inclusão Digital para Educadores:** Navegação simples para professores com pouca familiaridade técnica.
- **Desempenho Leve:** Otimizado para rodar de forma fluida em computadores antigos e Chromebooks da rede pública.
- **Código Aberto:** Permite que escolas e desenvolvedores personalizem jogos e atividades para a sua própria realidade.

## Como Executar o Projeto no Windows

### Pré-requisitos

- Computador rodando Windows 7 ou superior.
- Não é necessária a instalação de softwares adicionais para a versão compilada.

- Opicional: Opengl 2 ou superior, caso inferior, utilize ferramentas como o Mesa 3D Graphics Library. Versão 26.2.1. [S. l.]: freedesktop.org, 2026. Disponível em: https://www.mesa3d.org/. Acesso em: 23 ago. 2026.

### Passo a Passo

1. Baixe o executável mais recente na aba Releases do repositório.
2. Extraia o arquivo `.zip` para uma pasta de sua preferência.
3. Clique duas vezes no arquivo `ABCSimples.exe` para iniciar o aplicativo.
